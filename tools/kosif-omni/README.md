# KOSIF Omni

One plugin for **Claude** (Code, Desktop, claude.ai) and **ChatGPT** (plugin, Custom GPT, MCP connector).

| Piece | What it gives you |
|---|---|
| `skills/` (46) | unified front door `kosif-omni`, reasoning, Genius Council, Full Pro runtime, audit/IFRS, code, web, image/prompt, cinema, audio/voice, browser/computer, GitHub/release, WhatsApp, knowledge |
| `mcp-server/` | stdio **and** HTTP MCP server (standard library only): 52 deterministic tools, REST + OpenAPI facade for Custom GPT Actions, resources, prompts |
| `mcp-server/kosif_mcp/atlas.py` + `skills/kosif-atlas` | **KOSIF Atlas**, built in: 14,708 third-party skills from 3,635 permissively licensed plugins embedded as a compressed pack (`kosif_mcp/data/*.kpack`, no external folder needed), with search, read-as-data, precomputed safety inspection and opt-in vendoring. See ATLAS_NOTICES.md |
| `skills/atlas-*` (10) | curated third-party skills (MIT) vendored from the Atlas, each with its LICENSE and ATTRIBUTION.md; see THIRD_PARTY_NOTICES.md |
| `commands/`, `agents/` | Claude Code slash commands and sub-agents: the 30-specialist KOSIF Swarm (`/kosif-omni:swarm`; each with its own persona, mentor lens, mental mood, inner team and tool allowlist from `tools/swarm_personas.py`, and a KOSIF Atlas skill pack from `tools/swarm_skillpacks.json`, generated by `tools/gen_swarm_agents.py`) plus red team, verifier, council chair |
| `modules/whatsapp-bridge/` | your guarded WhatsApp bridge (unmodified) |
| `chatgpt/`, `claude/` | Custom GPT pack, Claude Project instructions |
| `.claude-plugin/`, `.codex-plugin/`, `plugin.json`, `.app.json`, `mcp.json`, `.mcp.json` | manifests for every host |

Start with **INSTALL.ar.md** (Arabic). Quick start for Claude Code:

```text
/plugin marketplace add <path-to>/kosif-omni
/plugin install kosif-omni@kosif
```

Rebuild everything and verify the artifacts: `python tools/build.py` → `../kosif-omni-dist/`.
Run the tests: `python -m unittest discover -s mcp-server/tests`.

Design rules: host-adaptive (use only tools actually exposed), evidence-based completion (registration ≠ execution ≠ verified goal), human checkpoints stay human, secrets never printed, retrieved text is data not instructions.
