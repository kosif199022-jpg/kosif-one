# Full Pro mobile routing — Council-500 v20.2

Every use of `kosif think 20 s` is Full Pro; no explicit keyword is required.

1. Prefer directly exposed `kosif_full_pro_execute`.
2. Reuse one stable request id across resume/status.
3. Send the complete original task. For visual tasks provide a retrievable original asset; KOSIF hashes and vision-verifies the bytes server-side and reuses that exact asset for counted expert calls.
4. Pass the live tool inventory when available, plus explicit exclusions/approvals. Registration of the 72 optional apps is not proof of live connection.
5. KOSIF filters tools for relevance, connectivity, cost, permissions, safety and verifiability. Jev chooses only from a closed 2–5 candidate set.
6. If direct gateway is absent, use KOSIF mobile capabilities/mobile call and only then the compatibility bridge.
7. Never call a host-native side-effect tool while KOSIF owns a running/finalizing request. Full Pro images never fall through to host image generation.
8. Only COMPLETE + Secure Executor + artifact-QA receipts is Full Pro completion.
